# 文化 🎭

> 让人心柔软的文学、艺术、传统、相遇。

## 收什么

- 优秀电影、剧集、书籍、游戏、动画的好消息
- 非遗传承、文物保护、考古重大发现
- 让人感动的文化瞬间（普通人的创作、跨文化的理解）
- 中国文化出海、汉服、中华美食的世界传播
- 音乐、舞蹈、绘画、戏剧的暖故事

## 不收什么

- 明星八卦、饭圈互撕
- 抄袭、抄袭、抄袭
- 烂片营销、流量注水

---

## 模板

每条新闻一个 `.md` 文件，文件名建议用日期 + 简短标题，例如 `2025-09-01-三星堆新出土青铜神树.md`。

```markdown
# 标题（中文，最好有温度）

**日期**：2025-09-01
**来源**：人民日报 / The Hollywood Reporter
**标签**：#非遗 #传统文化

## 一句话
用一句话讲完这条好消息。

## 发生了什么
2-4 句话，说清楚事件始末：谁、做了什么、影响范围。

## 为什么是好消息
1-2 句点出真正的积极意义，最好能让人会心一笑或心头一暖。

## 来源
- [原文标题](https://example.com/article-url)
```

## 示范条目

```markdown
# 91 岁敦煌修复师李云鹤获 UNESCO"杰出贡献奖"

**日期**：2025-09-01
**来源**：人民日报 / UNESCO
**标签**：#非遗 #敦煌 #文物保护

## 一句话
91 岁的敦煌研究院修复师李云鹤获 2025 年 UNESCO"杰出贡献奖"，60 年修复壁画 4000 平米。

## 发生了什么
李云鹤从 1963 年起在莫高窟做壁画修复，师从常书鸿、段文杰，自创"以旧修旧"工艺。他带出的 80 多个徒弟已成为全国壁画修复主力，2025 年获 UNESCO 杰出贡献奖，是首位获此荣誉的中国文保人。

## 为什么是好消息
有人用一辈子做一件事，让 1600 年的壁画再活一千年。

## 来源
- [原文标题](https://example.com)
```
