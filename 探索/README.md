# 探索 🚀

> 仰望星空、深潜海底、攀登极地——人类的好奇心在延伸世界的边界。

## 收什么

- 航天发射、探测器着陆、太空望远镜新发现
- 深海探索、极地科考、洞穴探险的科学成果
- 物理、化学、生物、数学的基础突破
- 民间航天、青少年科考的暖故事
- 古生物 / 古人类 / 考古的发现

## 不收什么

- 蹭流量的"UFO 视频"
- 未经同行评议的"重大发现"
- 危险伪科学（时间旅行、外星人阴谋等）

---

## 模板

每条新闻一个 `.md` 文件，文件名建议用日期 + 简短标题，例如 `2025-08-12-嫦娥七号月背采样返回成功.md`。

```markdown
# 标题（中文，最好有温度）

**日期**：2025-08-12
**来源**：NASA / ESA / 新华社
**标签**：#航天 #月球

## 一句话
用一句话讲完这条好消息。

## 发生了什么
2-4 句话，说清楚事件始末：谁、做了什么、影响范围。

## 为什么是好消息
1-2 句点出真正的积极意义，最好带上"人类第一次 / 突破性"等关键词。

## 来源
- [原文标题](https://example.com/article-url)
```

## 示范条目

```markdown
# 嫦娥七号在月球南极成功着陆，人类首次获取永冻层水冰样本

**日期**：2025-08-12
**来源**：国家航天局
**标签**：#航天 #月球 #水冰

## 一句话
嫦娥七号在月球南极艾特肯盆地成功软着陆，并钻取到 1.8 米深的永冻层样本，证实月球南极存在可用水冰。

## 发生了什么
嫦娥七号于 2025 年 8 月 12 日在月球南极艾特肯盆地永久阴影区附近着陆，钻取深度 1.8 米，样本中检测到 5.7% 重量的水冰。这是人类首次从月球南极永冻层获得样本，证明未来可建立月球基地。

## 为什么是好消息
月球有水 = 人类可以长期驻留月球 = 火星和深空的跳板。月球不再只是诗里的远方。

## 来源
- [原文标题](https://example.com)
```
