# 教育 📚

> 让孩子有学上、让普通人学到东西、让世界少一些不平等。

## 收什么

- 偏远地区学校建起来、孩子重返校园
- 优秀教师、免费教育资源、慕课
- 特殊教育、职业教育、终身教育的暖故事
- 高考、研究生教育中的温暖瞬间
- 中国/全球教育普及率提升、识字率提升

## 不收什么

- 教育内卷、应试焦虑
- 教师性侵、校园霸凌
- 教育产业化、培训机构跑路

---

## 模板

每条新闻一个 `.md` 文件，文件名建议用日期 + 简短标题，例如 `2025-03-01-云南山区新建10所小学.md`。

```markdown
# 标题（中文，最好有温度）

**日期**：2025-03-01
**来源**：人民日报 / The Guardian
**标签**：#乡村教育 #教育公平

## 一句话
用一句话讲完这条好消息。

## 发生了什么
2-4 句话，说清楚事件始末：谁、做了什么、影响范围。

## 为什么是好消息
1-2 句点出真正的积极意义。

## 来源
- [原文标题](https://example.com/article-url)
```

## 示范条目

```markdown
# 云南怒江：所有小学生告别溜索上学，新桥到校只要 10 分钟

**日期**：2025-03-01
**来源**：人民网
**标签**：#乡村教育 #教育公平

## 一句话
云南怒江 26 个村小告别溜索上学历史，新桥 / 公路直接通到学校门口。

## 发生了什么
随着最后一批"溜索学校"完成迁建，云南怒江 26 所村小的 4000 余名学生全部改走新桥 / 公路上学，平均上学时间从 1.5 小时缩短到 10 分钟。当地还配套了营养午餐和免费住宿。

## 为什么是好消息
最后一批"溜索上学"的孩子，终于能和城里孩子一样安全上学。

## 来源
- [原文标题](https://example.com)
```
