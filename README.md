## 怎么写一条好消息

每条新闻一个 `.md` 文件，文件名建议用日期 + 简短标题：

```
科技/2025-01-15-开源工具让5万盲人看见世界.md
```

模板（每个主题的 README 里都给了完整版和示范）：

```markdown
# 标题（中文，最好有温度）

**日期**：YYYY-MM-DD
**来源**：媒体名
**标签**：#tag1 #tag2

## 一句话
用一句话讲完这条好消息。

## 发生了什么
2-4 句话，说清楚事件始末。

## 为什么是好消息
1-2 句点出真正的积极意义。

## 来源
- [原文标题](url)
```

## 选稿原则

只收**真实**、**客观**、**有数据 / 有具名信源**的好消息。

- ✅ 真实事件、有公开报道
- ✅ 让人温暖 / 让人相信人性的故事
- ❌ 自媒体未证实传闻
- ❌ 营销稿、PR 通稿
- ❌ 强行煽情、堆砌情绪
