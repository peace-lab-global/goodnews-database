# 环境 🌿

> 物种被保护、森林在恢复、空气在变好、海豚回来了。

## 收什么

- 濒危物种数量回升、保护区建立
- 森林、湿地、海洋生态恢复
- 空气质量改善、可再生能源里程碑
- 极端天气应对、灾后温暖互助
- 普通人/小团队的环保行动

## 不收什么

- 气候焦虑、末日预言
- 单纯环保政策 PR（除非有真实生态数据好转）
- 动物表演、消费陷阱

---

## 模板

每条新闻一个 `.md` 文件，文件名建议用日期 + 简短标题，例如 `2025-04-22-大熊猫野外种群数量回升.md`。

```markdown
# 标题（中文，最好有温度）

**日期**：2025-04-22
**来源**：新华社 / BBC
**标签**：#生态恢复 #野生动物

## 一句话
用一句话讲完这条好消息。

## 发生了什么
2-4 句话，说清楚事件始末：谁、做了什么、影响范围。

## 为什么是好消息
1-2 句点出真正的积极意义，最好带上数据。

## 来源
- [原文标题](https://example.com/article-url)
```

## 示范条目

```markdown
# 长江江豚回来了！种群数量止跌回升至 1249 头

**日期**：2025-04-22
**来源**：农业农村部
**标签**：#生态恢复 #长江 #野生动物

## 一句话
曾被宣告"功能性灭绝"的长江江豚，种群数量 5 年回升 23.4%，达 1249 头。

## 发生了什么
农业农村部 2025 年最新科考显示，长江江豚从 2020 年的 1012 头回升到 1249 头，分布范围也由 6 个江段扩展到 11 个。2021 年开始的长江十年禁渔、增殖放流和栖息地修复被认为是关键。

## 为什么是好消息
长江江豚是长江生态系统的旗舰物种，它的回归意味着整条母亲河的健康在恢复。

## 来源
- [原文标题](https://example.com)
```
