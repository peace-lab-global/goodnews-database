# 国际 🌍

> 全世界都在变好、人类依然值得期待。

## 收什么

- 全球疾病消除、贫困率下降
- 国际救援、人道主义行动
- 跨国合作、和平进程
- 全球性技术突破（ITER、CERN、SpaceX……）
- 让人相信人性的国际暖闻

## 不收什么

- 战争、恐袭、恶性治安事件
- 政客互喷、选举闹剧
- 阴谋论、伪科学

---

## 模板

每条新闻一个 `.md` 文件，文件名建议用日期 + 简短标题，例如 `2025-07-01-全球疟疾疫苗推广覆盖非洲10国.md`。

```markdown
# 标题（中文，最好有温度）

**日期**：2025-07-01
**来源**：联合国新闻 / Reuters
**标签**：#公共卫生 #全球合作

## 一句话
用一句话讲完这条好消息。

## 发生了什么
2-4 句话，说清楚事件始末：谁、做了什么、影响范围。

## 为什么是好消息
1-2 句点出真正的积极意义，最好带上覆盖人群 / 地区。

## 来源
- [原文标题](https://example.com/article-url)
```

## 示范条目

```markdown
# WHO：全球新增结核病例 5 年下降 22%，逆转 20 年上升趋势

**日期**：2025-07-01
**来源**：WHO / 路透社
**标签**：#公共卫生 #全球健康

## 一句话
世界卫生组织 2024 年全球结核病报告：5 年内全球新增结核病例下降 22%，扭转 2003 年以来的上升趋势。

## 发生了什么
WHO 发布的最新报告显示，2020-2024 年全球新增结核病例从 1030 万下降至 800 万，其中东南亚、非洲下降最显著。新药贝达喹啉、更短 4 个月治疗方案和 AI 辅助筛查被认为是三大主因。

## 为什么是好消息
结核是全球头号传染病杀手，"终结结核"曾是 WHO 看起来遥不可及的目标，现在首次出现真实下降拐点。

## 来源
- [原文标题](https://example.com)
```
