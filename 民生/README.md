# 民生 🏘️

> 普通人过上好日子、让打工人被善待的每一件小事。

## 收什么

- 工资、福利、假期、带薪政策的改善
- 就业、创业、灵活工作机会
- 住房保障、租金友好、老旧小区改造
- 育儿、养老、残疾人关爱
- 食品安全、消费者权益保护的好案例
- 凡人善举、邻里互助、社区温暖

## 不收什么

- 加班文化、35 岁焦虑
- 食品安全事件
- 贫富差距、阶层对立
- 烂尾楼、维权

## 模板

每条新闻一个 `.md` 文件，文件名建议用日期 + 简短标题，例如 `2025-05-01-某地试行四天工作制.md`。

```markdown
# 标题（中文，最好有温度）

**日期**：2025-05-01
**来源**：工人日报 / 36 氪
**标签**：#劳动者权益 #带薪假期

## 一句话
用一句话讲完这条好消息。

## 发生了什么
2-4 句话，说清楚事件始末：谁、做了什么、影响范围。

## 为什么是好消息
1-2 句点出真正的积极意义，最好带上覆盖人群数量。

## 来源
- [原文标题](https://example.com/article-url)
```

## 示范条目

```markdown
# 杭州一公司试行四天工作制一年：营收没降，员工幸福感暴涨

**日期**：2025-05-01
**来源**：36 氪
**标签**：#劳动者权益 #工作制度

## 一句话
杭州某互联网公司试行"周五不上班"一年后，营收同比 +8%，员工 NPS 提升 35 分。

## 发生了什么
该公司 2024 年 5 月起试行"每周四天工作制"，工资不变。一年后公司发布年报：营收同比增长 8%，离职率从 18% 降至 6%，员工 NPS 提升 35 分。CEO 表示生产效率提升来自会议削减和深度工作时间增加。

## 为什么是好消息
给"打工人"提供了一种可能：少上班，也能好好工作。

## 来源
- [原文标题](https://example.com)
```
