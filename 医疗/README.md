# 医疗 🏥

> 救命药、暖医患、被治愈的人、消失的病。

## 收什么

- 重大疾病的新疗法、新药获批（尤其是曾经无药可救的病）
- 罕见病患者的治愈故事
- 医护人员的暖心瞬间
- 医疗下沉、基层医疗改善
- 公共卫生的胜利（某种疾病被消灭/大幅减少）

## 不收什么

- 医患矛盾、医疗系统负面
- 未经证实的"神药"
- 个案偏方、保健品广告

---

## 模板

每条新闻一个 `.md` 文件，文件名建议用日期 + 简短标题，例如 `2025-02-10-基因编辑治愈镰刀型贫血.md`。

```markdown
# 标题（中文，最好有温度）

**日期**：2025-02-10
**来源**：健康报 / STAT News
**标签**：#基因治疗 #罕见病

## 一句话
用一句话讲完这条好消息。

## 发生了什么
2-4 句话，说清楚事件始末：谁、做了什么、影响范围。

## 为什么是好消息
1-2 句点出真正的积极意义。

## 来源
- [原文标题](https://example.com/article-url)
```

## 示范条目

```markdown
# 全球首例：CRISPR 治愈的镰刀型贫血患者，已健康生活 5 年

**日期**：2025-02-10
**来源**：NEJM / STAT News
**标签**：#基因治疗 #罕见病 #CRISPR

## 一句话
全球首位接受 CRISPR 基因编辑治疗镰刀型贫血的患者维多利亚，5 年后仍完全摆脱输血，过着正常生活。

## 发生了什么
2020 年，美国田纳西一名叫维多利亚的女婴成为全球首位接受 CRISPR 临床试验的患者。5 年随访数据显示，她的血红蛋白恢复正常，不再需要每月输血，发育和同龄人无异。2024 年底 FDA 正式批准该疗法上市。

## 为什么是好消息
镰刀型贫血全球患者超 2000 万，长期无治愈方案；现在一次治疗，终身受益。基因医学从科幻走到日常。

## 来源
- [原文标题](https://example.com)
```
