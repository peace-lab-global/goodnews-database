# 体育 ⚽

> 公平竞争、坚持到底、让人起鸡皮疙瘩的瞬间。

## 收什么

- 重大赛事冠军、世界纪录、突破性成绩
- 残奥、特奥、青少年体育的暖故事
- 草根体育、社区体育、乡村学校体育
- 运动员退役 / 转型 / 助人的好故事
- 体育让普通人变得更好的真实案例

## 不收什么

- 兴奋剂、假球、黑哨
- 球迷冲突、赛场暴力
- 运动员八卦

---

## 模板

每条新闻一个 `.md` 文件，文件名建议用日期 + 简短标题，例如 `2025-10-01-中国女篮时隔12年再夺亚洲杯.md`。

```markdown
# 标题（中文，最好有温度）

**日期**：2025-10-01
**来源**：新华社 / ESPN
**标签**：#国家队 #突破

## 一句话
用一句话讲完这条好消息。

## 发生了什么
2-4 句话，说清楚事件始末：谁、做了什么、影响范围。

## 为什么是好消息
1-2 句点出真正的积极意义，最好能让人热血沸腾。

## 来源
- [原文标题](https://example.com/article-url)
```

## 示范条目

```markdown
# 31 岁老将巩立姣亚锦赛第十次夺冠，赛后把金牌挂到对手脖子上

**日期**：2025-10-01
**来源**：新华社
**标签**：#田径 #体育精神

## 一句话
31 岁的巩立姣在亚洲田径锦标赛女子铅球项目第十次夺冠，颁奖时主动把金牌挂到同场竞技的日本新星脖子上。

## 发生了什么
巩立姣以 19.58 米夺冠，这是她第十次站上亚锦赛铅球最高领奖台。颁奖时她注意到日本 19 岁新星田中结月紧张得说不出话，主动走过去把金牌挂到她脖子上，全场掌声雷动。

## 为什么是好消息
冠军的温柔，比金牌更动人。

## 来源
- [原文标题](https://example.com)
```
