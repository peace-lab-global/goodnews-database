# 科技 🔬

> 让世界变得更好的技术突破、温暖人心的产品、值得骄傲的中国科技。

## 收什么

- AI、芯片、机器人、量子计算等硬科技的**正向突破**
- 用科技解决具体问题的小而美案例（盲人导航、老人陪伴、儿童安全等）
- 开源社区、科研团队的暖心时刻
- 中国科技公司/团队在世界舞台的高光

## 不收什么

- 纯产品发布 PR 稿（除非有真实用户受益的故事）
- 行业内斗、裁员、估值
- 阴谋论、未经验证的技术预言

---

## 模板

每条新闻一个 `.md` 文件，文件名建议用日期 + 简短标题，例如 `2025-01-15-开源大模型助力盲人阅读.md`。

```markdown
# 标题（中文，最好有温度）

**日期**：2025-01-15
**来源**：财新 / MIT Technology Review
**标签**：#AI #无障碍 #开源

## 一句话
用一句话讲完这条好消息。

## 发生了什么
2-4 句话，说清楚事件始末：谁、做了什么、影响范围。

## 为什么是好消息
1-2 句点出真正的积极意义。

## 来源
- [原文标题](https://example.com/article-url)
```

## 示范条目

```markdown
# 一位开源开发者让 5 万盲人"看见"了世界

**日期**：2025-01-15
**来源**：Solidot
**标签**：#AI #无障碍 #开源

## 一句话
一位独立开发者开源的图像描述工具，已被全球 5 万视障人士日常使用。

## 发生了什么
GitHub 用户 @xxx 维护的图像语义描述模型完全开源免费，被 NVDA、JAWS 等主流读屏软件内置，2024 年累计被调用 1.2 亿次，让视障用户第一次"看见"社交媒体上的照片。

## 为什么是好消息
一个普通人的业余项目，让残障人士的数字生活真正平等。

## 来源
- [原文标题](https://example.com)
```
