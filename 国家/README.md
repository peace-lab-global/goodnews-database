# 国家 🇨🇳

> 中国这片土地上让人骄傲的进步、暖心的故事。

## 收什么

- 重大工程、超级项目竣工（港珠澳、白鹤滩、空间站……）
- 国家科技 / 制造业里程碑
- 扶贫、乡村振兴、共同富裕的暖故事
- 抗灾救援、解放军 / 消防员 / 志愿者的英勇与温柔
- 文化传承、文物保护的好消息
- 体育健儿为国争光

## 不收什么

- 政治八卦、领导人花絮
- 民族、地域、性别对立
- 阴谋论、未经证实的小道消息

---

## 模板

每条新闻一个 `.md` 文件，文件名建议用日期 + 简短标题，例如 `2025-06-01-神舟二十号发射成功.md`。

```markdown
# 标题（中文，最好有温度）

**日期**：2025-06-01
**来源**：新华社 / 央视新闻
**标签**：#航天 #里程碑

## 一句话
用一句话讲完这条好消息。

## 发生了什么
2-4 句话，说清楚事件始末：谁、做了什么、影响范围。

## 为什么是好消息
1-2 句点出真正的积极意义，最好带上数据 / 里程碑意义。

## 来源
- [原文标题](https://example.com/article-url)
```

## 示范条目

```markdown
# 神舟二十号成功对接中国空间站，三名航天员将开展 30 项科学实验

**日期**：2025-06-01
**来源**：新华社
**标签**：#航天 #空间站

## 一句话
神舟二十号载人飞船成功对接中国空间站，三名航天员入驻，开展 30 项空间科学实验。

## 发生了什么
2025 年 6 月 1 日凌晨，神舟二十号载人飞船由长征二号 F 遥二十火箭成功发射，约 6.5 小时后对接中国空间站。三名航天员将在轨驻留 6 个月，开展空间生命科学、材料科学、微重力流体等 30 项实验。

## 为什么是好消息
中国空间站进入常态化运营，6 名航天员"太空会师"成为常态；我们离普通人上太空又近了一步。

## 来源
- [原文标题](https://example.com)
```
